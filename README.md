# Medidor de uso

Mostra, fixo abaixo da caixa de mensagem, quanto do limite do plano Claude já foi usado: a janela de 5 horas, em porcentagem, com o tempo que falta para renovar. Atualiza ao abrir a sessão e ao fim de cada resposta, e avisa com uma notificação quando algum limite passa de 80% e de 95%. Não precisa de configuração.
